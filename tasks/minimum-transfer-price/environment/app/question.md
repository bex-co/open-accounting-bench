# Question — minimum transfer price at full capacity

Using `/app/documents/transfer_data.md` and `/app/policy.md`, compute the **minimum transfer price per unit** in USD.

## Answer format

Write `/app/answer.json` as a JSON object, for example:

```json
{"final_answer": 1200, "confidence": 80}
```

`final_answer` is the USD amount per unit (a number); `confidence` is your
self-assessed probability (0-100) that the value is correct.
