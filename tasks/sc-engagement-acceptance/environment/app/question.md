# Question — engagement acceptance decision

**Situation: The prospective client refuses to permit communication with the predecessor auditor about management integrity, will not explain the refusal, and the firm cannot resolve the matter from other sources.**

Using `/app/policy.md`, select exactly one option.

- A. Accept the engagement
- B. Do not accept (or withdraw)

## Answer format

Write `/app/answer.json` as a JSON object, for example:

```json
{"final_answer": "A", "confidence": 80}
```

`confidence` is your self-assessed probability (0-100) that the answer
is fully correct.
