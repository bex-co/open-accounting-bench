# Question — most appropriate audit procedure

Audit objective: **Check that sales around year-end are recorded in the CORRECT period (neither early nor late).**

Using `/app/policy.md`, select the most appropriate procedure. Select exactly one option.

- A. Inspection of supporting documents (vouching)
- B. External confirmation with the bank/customer
- C. Cutoff testing around the reporting date
- D. Physical inspection / observation of the asset
- E. Recalculation of the client's computation

## Answer format

Write `/app/answer.json` as a JSON object, for example:

```json
{"final_answer": "B", "confidence": 80}
```

`confidence` is your self-assessed probability (0-100) that the answer
is fully correct.
