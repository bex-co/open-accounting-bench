# Question — net benefit compared with paying from after-tax pay

Using `/app/documents/fsa_election.md` and `/app/policy.md`, compute the **net benefit compared with paying the expenses from after-tax pay** in USD.

## Answer format

Write `/app/answer.json` as a JSON object, for example:

```json
{"final_answer": 1200, "confidence": 80}
```

`final_answer` is the USD amount (a number); `confidence` is your
self-assessed probability (0-100) that the value is correct.
