# Question — number of Type A programs

Using `/app/documents/federal_awards.md` and `/app/policy.md`, compute the **number of Type A programs**.

## Answer format

Write `/app/answer.json` as a JSON object, for example:

```json
{"final_answer": 1200, "confidence": 80}
```

`final_answer` is the count (a number); `confidence` is your
self-assessed probability (0-100) that the value is correct.
