# Question — control assessment

Facts: **The investor holds 48% of the votes and also holds currently exercisable, deep in-the-money options over a further 10%, which the other shareholders cannot block.**

Using `/app/policy.md`, what is the investor's relationship with the investee? Select exactly one option.

- A. Significant influence only — do not consolidate
- B. Neither control nor significant influence
- C. Control — consolidate

## Answer format

Write `/app/answer.json` as a JSON object, for example:

```json
{"final_answer": "B", "confidence": 80}
```

`confidence` is your self-assessed probability (0-100) that the answer
is fully correct.
