# Question — payback period

Using `/app/documents/project_screening.md` and `/app/policy.md`, compute the **payback period in years**.

## Answer format

Write `/app/answer.json` as a JSON object, for example:

```json
{"final_answer": 1200, "confidence": 80}
```

`final_answer` is the number of years (a number); `confidence` is your
self-assessed probability (0-100) that the value is correct.
