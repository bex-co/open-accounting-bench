# Question — direct materials used

Using `/app/documents/raw_materials.md` and `/app/policy.md`, compute **direct materials used** in January in USD.

## Answer format

Write `/app/answer.json` as a JSON object, for example:

```json
{"final_answer": 1200, "confidence": 80}
```

`final_answer` is the USD amount (a number); `confidence` is your
self-assessed probability (0-100) that the value is correct.
