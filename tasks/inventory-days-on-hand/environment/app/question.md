# Question — days' inventory on hand

Using `/app/documents/inventory_data.md` and `/app/policy.md`, compute **days' inventory on hand**.

## Answer format

Write `/app/answer.json` as a JSON object, for example:

```json
{"final_answer": 1200, "confidence": 80}
```

`final_answer` is the number of days (a number); `confidence` is your
self-assessed probability (0-100) that the value is correct.
