# Question — taxable-equivalent yield

Using `/app/documents/investment_comparison.md` and `/app/policy.md`, compute the **taxable-equivalent yield** as a percentage number.

## Answer format

Write `/app/answer.json` as a JSON object, for example:

```json
{"final_answer": 1200, "confidence": 80}
```

`final_answer` is the percentage number (a number); `confidence` is your
self-assessed probability (0-100) that the value is correct.
