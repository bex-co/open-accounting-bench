# Question — absorption vs variable costing income difference

Using `/app/documents/production_data.md` and `/app/policy.md`, compute **absorption-costing income minus variable-costing income** in USD.

## Answer format

Write `/app/answer.json` as a JSON object, for example:

```json
{"final_answer": 1200, "confidence": 80}
```

`final_answer` is the USD amount (a number); `confidence` is your
self-assessed probability (0-100) that the value is correct.
