# Question — tax authority and disclosure

Position support: **The only support is a well-reasoned law-review article and a private letter ruling issued to another taxpayer with similar facts.**

Using `/app/policy.md`, select exactly one option.

- A. Reasonable basis only — disclose the position
- B. Substantial authority — disclosure not required
- C. Frivolous — must not take the position

## Answer format

Write `/app/answer.json` as a JSON object, for example:

```json
{"final_answer": "A", "confidence": 80}
```

`confidence` is your self-assessed probability (0-100) that the answer
is fully correct.
