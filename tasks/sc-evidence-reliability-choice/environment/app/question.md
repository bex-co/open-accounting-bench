# Question — most reliable audit evidence

**Existence of the year-end bank balance. Which single item is MOST reliable?**

Using `/app/policy.md`, select exactly one option.

- A. Oral assurance from the treasurer
- B. The client's bank reconciliation schedule
- C. Photocopy of the bank statement supplied by the client
- D. Original confirmation received directly from the bank

## Answer format

Write `/app/answer.json` as a JSON object, for example:

```json
{"final_answer": "A", "confidence": 80}
```

`confidence` is your self-assessed probability (0-100) that the answer
is fully correct.
