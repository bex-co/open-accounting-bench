# Question — recorded vs expected revenue

Using `/app/documents/hotel_data.md` and `/app/policy.md`, compute **recorded revenue minus the independent expectation** in USD.

## Answer format

Write `/app/answer.json` as a JSON object, for example:

```json
{"final_answer": 1200, "confidence": 80}
```

`final_answer` is the signed USD amount (a number); `confidence` is your
self-assessed probability (0-100) that the value is correct.
