# Question — diluted earnings per share

Using `/app/documents/eps_data.md` and `/app/policy.md`, compute **diluted earnings per share** in USD.

## Answer format

Write `/app/answer.json` as a JSON object, for example:

```json
{"final_answer": 1200, "confidence": 80}
```

`final_answer` is the USD amount per share (a number); `confidence` is your
self-assessed probability (0-100) that the value is correct.
