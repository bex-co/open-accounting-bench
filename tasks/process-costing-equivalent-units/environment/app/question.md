# Question — equivalent units (weighted-average)

Using `/app/documents/production_data.md` and `/app/policy.md`, compute January **equivalent units for conversion costs**.

## Answer format

Write `/app/answer.json` as a JSON object, for example:

```json
{"final_answer": 1200, "confidence": 80}
```

`final_answer` is the equivalent-unit count (a number); `confidence` is your
self-assessed probability (0-100) that the value is correct.
