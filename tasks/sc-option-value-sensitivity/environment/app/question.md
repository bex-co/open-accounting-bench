# Question — option value sensitivity

Question: **All else equal, the time to expiration of an American CALL option is longer. Effect on its value?**

Using `/app/policy.md`, select exactly one option.

- A. Increases
- B. No change
- C. Decreases

## Answer format

Write `/app/answer.json` as a JSON object, for example:

```json
{"final_answer": "A", "confidence": 80}
```

`confidence` is your self-assessed probability (0-100) that the answer
is fully correct.
