# Question — debt covenant leverage ratio

Using `/app/documents/covenant_data.md` and `/app/policy.md`, compute the **covenant leverage ratio**.

## Answer format

Write `/app/answer.json` as a JSON object, for example:

```json
{"final_answer": 1200, "confidence": 80}
```

`final_answer` is the ratio (a number); `confidence` is your
self-assessed probability (0-100) that the value is correct.
