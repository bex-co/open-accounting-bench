## Objective

Add a registry (family → status pending/reviewed, reviewer, date, generator version reviewed) and a CI check that it agrees with `TO_REVIEW.md`. Only a human reviewer sets `reviewed`; tooling validates but never writes that status.

## Context

- `TO_REVIEW.md`; review rules in `docs/governance.md`.
- Family registry: `FAMILIES` in `src/oab/families.py`.

## Steps

1. Define the file format.
2. Seed it from `TO_REVIEW.md`.
3. Add validation to `make validate` or a new target.

## Files

- reviews.toml (new)
- src/oab/cli.py
- tests/

## Acceptance criteria

- [ ] Every registered family has exactly one registry row
- [ ] CI fails if a family is missing or the registry contradicts `TO_REVIEW.md`
