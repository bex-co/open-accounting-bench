## Objective

Specify the mutations that probe the grader. False-accept probes (should fail): edit or delete an existing entry, plug the difference to a suspense or clearing account, open a new account, post outside the period, double-post, game `answer.json` structure or tolerance. False-reject probes (should pass): equivalent decompositions — split or merged entries, posting order, compound vs simple entries.

## Context

- Five layers: `docs/verification.md#five-layers`; equivalence rules: `docs/verification.md#multiple-correct-answers`.
- Formats in `tasks/manifest.json`: journal-entry, numeric, single-choice, multiple-choice, workflow.
- Existing per-family traps: `tests/test_verifier.py`, `tests/test_answer_grader.py`.

## Steps

1. Enumerate operators per format with the expected verdict for each.
2. Write them as pure functions over a solved ledger or answer file.
3. Document each operator in the module docstring.
