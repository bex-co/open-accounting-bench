## Objective

Run `oab audit` on the committed tree. For each misjudgement, either fix the grader or the task (starting with a failing test, regenerating tasks in the same commit, and deciding on a `GENERATOR_VERSION` bump) or record it as a documented known limit with a reason.

## Context

- Verifier changes start with a failing test and regenerate tasks (`AGENTS.md` rules).
- Versioning: `docs/governance.md`.

## Steps

1. Run the audit.
2. Triage each finding: fix or document.
3. Re-run until only documented limits remain.
