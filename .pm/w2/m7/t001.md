## Objective

For a subset of issues, make the obvious source incomplete and put the decisive detail in a secondary file (for example a summary cutoff schedule without dates while the full shipping log has them).

## Context

- FinancialAuditBench's largest failure class (25%) is insufficient retrieval: agents stop at the obvious document.

## Steps

1. Pick at least five issues.
2. Split their facts between a primary summary and a secondary detailed source.
3. Add a trap that uses only the primary source.
