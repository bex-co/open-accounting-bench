# Declared plausibility invariants for generator seed sweeps

Accounting reviews keep finding seeds that are valid but unrealistic
(implied prices inconsistent across stakes, negative adjusted basis,
bundled price far from standalone prices). Let a generator declare
plausibility invariants (ratios, sign constraints, bounds) and have the
1,000-seed sweep in `tests/test_generators.py` check them.

- Bounds come from textbook and public practice conventions only — no
  real records (`.pm/DO_NOT_DO.md`, PROVENANCE.md).
- Start with the scaffold plus three families; promote to a milestone
  if rolling it out across all families is wanted.
- Pillar B1. About 1h for the scaffold.

---

**Resolved 2026-11-05** — closed by triage, no new code: seed-sweep plausibility invariants already exist on `main` as `tests/test_generators.py::test_scenario_sanity_sweeps` (d9f843b) and `::test_review_regressions_seed_sweeps` (1c0ecd7, extended in c35ce58), asserting textbook/practice bounds over seeds 0-999 for the families reviews flagged (non-negative adjusted basis, §754 adjustment within appreciation, bundled price 0.75-1.05x standalone prices, retained-stake ratio 0.5-1.05, non-zero warranty movement, and others). A generator-side declaration API would restate these checks without adding coverage, so it was not built; new findings add an assertion to those sweeps.
