## Objective

Run a deterministic sample of the audit in CI so a new false accept or false reject fails the build.

## Context

- CI: `.github/workflows/ci.yml`; Makefile targets.

## Steps

1. Add `make audit` (sampled) and call it in CI.
2. Keep runtime under a few minutes.

## Files

- Makefile
- .github/workflows/ci.yml

## Acceptance criteria

- [ ] CI fails when a known-good operator starts misjudging
- [ ] `make audit` runtime is recorded in the PR

## Out of scope

- Full audit on every push
