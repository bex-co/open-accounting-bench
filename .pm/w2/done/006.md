# loopx guard picks milestones in string order

`scripts/loopx-guard.py` sorts milestone directories by name
(`sorted(p.name for p in root.glob("m*"))`), so with `m10` present it
names `m10` as the next pick while `m6`–`m9` are still open. The
`/loopx` skill picks the lowest-*numbered* milestone, so the hook's
hint disagrees with the skill (it still correctly detects that work
remains).
