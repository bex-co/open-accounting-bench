# Evaluate keyed seed derivation for the Holdout track

Assess whether Holdout instances should derive seeds through a keyed
function (for example HMAC with an unpublished key), so that public
generators cannot reconstruct Holdout instances by enumerating seeds.

- Write up the threat model and a recommendation in
  `docs/governance.md#holdout-track` terms only — no Holdout families,
  seeds, or expectations here or in any public file.
- Reference practice: keyed generation identity in the open
  beancount-ledger environment.
- Pillar B1. Sub-hour evaluation.
