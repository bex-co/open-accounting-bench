# Calibrate the month-end pilot on pass^k under fixed budgets

`docs/methodology.md` and `docs/metrics.md` set the pilot's preregistered
target band on mean rubric completion (40-70%), which the 0.8.0 strong
tiers exceeded at 97-99%. Comparable benchmarks report sharp drops from
single-run to every-run success (FinancialAuditBench 69% -> 44% at
k=8; APEX Pass^8 <= 2.6%) and large budget effects (APEX: +43 points
from $1 to $50 for one model).

- Define the next panel's target band on pass^k (`oab report --k`) with
  rubric completion as a diagnostic, and require a fixed per-trial
  budget tier recorded with the panel.
- Docs-only change; sub-hour. Pillar B3/B1.
